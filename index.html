Marketplace Notes — Privacy Policy

Last updated: October 28, 2026

Marketplace Notes is a browser extension that lets users add private notes to saved marketplace listings and, on supported sites, identify price changes observed during subsequent visits. It supports Turbo.az, Tap.az, Bina.az, and Boss.az.

Information the extension handles

  • Personal notes: text that a user chooses to write for an individual listing.
  • Listing references: listing identifiers or URLs used to associate a note with the correct listing.
  • Observed listing prices: price values and related local records used to compare prices seen on different visits.
  • Page information: relevant listing content, such as the current price and listing links, read from supported marketplace pages so the extension can display its features.

Where information is stored

Notes and observed-price records are stored locally in the user's browser using the Chrome extension storage API. The extension does not operate its own account system or backend server for these features. Removing the extension or clearing its stored data may remove locally saved notes and price records.

How information is used

The information described above is used only to associate notes with listings, display those notes on supported marketplace pages, and show price changes when a different price is observed. The extension does not use this information for advertising, profiling, credit decisions, or unrelated purposes.

Sharing and sale

Marketplace Notes does not sell users' notes or locally stored listing records, and does not transmit them to the extension developer. The extension reads supported marketplace pages in the user's browser to provide its features. Those websites remain subject to their own privacy policies and practices.

Permissions

The storage permission is used to save notes and observed-price records locally. Access to supported marketplace websites is used to read relevant listing information and display the extension's interface on those pages.

Data retention and control

Users can edit or delete their notes through the extension. Locally stored data remains in the browser until it is changed or removed by the user, or removed when the extension's stored data is cleared or the extension is uninstalled.

Children's privacy

Marketplace Notes is a general-purpose browser utility and is not designed to collect personal information from children.

Changes to this policy

This policy may be updated if the extension's functionality or data practices change. The latest version will be published at this page.
